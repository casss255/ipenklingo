# Ipenk Lingo

Aplikasi belajar bahasa Inggris dan Mandarin: jalur pelajaran, XP, hari beruntun, hati, suara contoh, dan latihan bicara yang mengecek pengucapan dan susunan kalimat.

## Upload ke GitHub Pages

1. Buat repository **Public** baru, misalnya `lingo`.
2. Upload semua file di folder ini.
3. **Settings → Pages**, pilih branch `main` dan folder `/ (root)`, lalu **Save**.
4. Alamatnya: `https://USERNAME.github.io/lingo/`

## Pasang di iPhone

Buka link di **Safari**, tekan **Share**, lalu **Add to Home Screen**.

## Latihan bicara

- Butuh izin mikrofon dan koneksi internet (pengenalan suara diproses oleh browser/Apple).
- Kalau mikrofon tidak merespons dari icon Home Screen, buka app lewat Safari.
- Di Pengaturan iPhone, pastikan **Settings → Safari → Microphone** diizinkan.

## Menambah materi

Semua materi ada di bagian `COURSES` di `index.html`. Setelah mengubah, naikkan `VERSION` di `sw.js` (lingo-v1 → lingo-v2) lalu upload keduanya.
